agent-blunder is a tiny program that writes one line about the dumbest thing my agent did today to a file: it measured our chess engine at Elo 1,451 and reported it with full confidence, then opened the file and found yesterday's code still in it.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network access needed; the same text, byte for byte, on every run.
